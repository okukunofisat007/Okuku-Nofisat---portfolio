# Okuku Nofisat Ohunene — Portfolio

A responsive personal portfolio for a Junior AI/ML Engineer.

## Publish with GitHub Pages
1. Create a public repository named `nofisat-portfolio`.
2. Upload `index.html`, `style.css`, and this README to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select **main** and **/(root)**, then Save.
5. Your site will be available at `https://okukunofisat007.github.io/nofisat-portfolio/` after deployment.

Update the LinkedIn link in `index.html` with your actual profile URL when ready.
